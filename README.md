# Сайт-приглашение на свадьбу — Екатерина и Артём, 27.08.2027

Готовый статический сайт: без сборки, без зависимостей, без бэкенда.
Открывается двойным кликом по `index.html`, работает на телефоне и в десктопном браузере.

## Что уже есть

| Блок | Что внутри |
|---|---|
| 1. Обложка | имена, дата, живой отсчёт до свадьбы |
| 2. Приглашение | календарь на август 2027 (выделено 27-е) + текст приглашения; кнопка «Добавить в календарь» (`.ics` для iPhone/Android) |
| 3. Место и программа | адрес д. Летенец, Школьная 2Б с кнопками Яндекс/Google Карт + таймлайн дня |
| 4. Тест | 5 вопросов-заготовок, легко заменить на свои |
| 5. RSVP | имя, придёт/не придёт, с кем, еда, трансфер, контакт, комментарий |

Плюс: плавающее меню, плавные появления секций, мобильная адаптация, `noscript`-фоллбэк,
печатная версия, favicon, `og:`-мета для красивой ссылки в мессенджерах.

## Что уже настроено

- Ответы можно отправлять автоматически в Google-таблицу и в Telegram:
  для этого разверните `apps-script/Code.gs` (файл лежит рядом с папкой `wedding`)
  и вставьте URL веб-приложения в `CONFIG.scriptUrl`. Инструкция — ниже,
  раздел «Вариант 1».
- Пока `CONFIG.scriptUrl` пустой, работает резерв: гость жмёт «В Telegram»
  и отправляет текст сам (`CONFIG.telegram = 'artiom_gorch'`).
- WhatsApp пока работает как «поделиться» (номер не указан). Укажете номер в
  `CONFIG.whatsapp` — кнопка станет прямой, как в Telegram.

## Как посмотреть локально

Вариант 1 — просто открыть `index.html` в браузере (двойной клик).

Вариант 2 — локальный сервер (ближе к реальности, работает и на телефоне):

```powershell
cd wedding
python -m http.server 5500
```

Затем на компьютере `http://127.0.0.1:5500`, на телефоне (тот же Wi-Fi)
`http://<IP-компьютера>:5500` — IP смотрите через `ipconfig`.

## Что поменять под себя

- **Имена, дата, тексты** — `index.html`. Ищите «Екатерина», «Артём», «Летенец».
- **Дата для отсчёта и для `.ics`** — `CONFIG.date` и `CONFIG.event` в `js/main.js`.
- **Вопросы теста** — скопируйте любое `<div class="field">` с `.pills` внутри формы `#quizForm`
  и поменяйте подписи. Главное — уникальные `name="q1"`, `q2`, …
- **Фото** — замените `assets/hero.jpg` и `assets/hero-mobile.jpg` своими.
  Проще всего: положить фото 1700×1133 и 900×1400 (JPG, качество 75–80).
- **Адреса карт** — ссылки в блоке «Место проведения» (`href` у кнопок).
- **Дресс-код, подарки, пожелания** — добавьте новый `<p>` в `.invite__text` или новую `.card`.

## Ответы гостей: выберите один из вариантов

По умолчанию сервер не подключён — форма проверяет данные, сохраняет ответ
в браузере гостя и показывает готовый текст. Это резерв, а не сбор ответов.

### Вариант 1 (рекомендую): Google Таблица + бот в Telegram

Ответы сами падают в Google-таблицу и приходят сообщением в Telegram.
Бесплатно, без лимитов, гость просто нажимает «Отправить» и всё.

1. Создайте таблицу: [sheets.new](https://sheets.new) (название любое).
2. В таблице: **Расширения → Apps Script**.
3. Удалите код-заглушку и вставьте целиком файл `apps-script/Code.gs`
   (лежит рядом с папкой `wedding`).
4. В начале файла впишите токен бота в `TG_TOKEN` — токен даёт
   [@BotFather](https://t.me/BotFather): `/newbot` → имя → `@username` → токен.
5. Откройте своего бота в Telegram и нажмите **«Запустить»** (/start).
   Без этого бот не имеет права вам писать.
6. В Apps Script выберите функцию `setup` → **Выполнить**. Google попросит
   разрешения: «Дополнительные настройки» → «Перейти к проекту (небезопасно)» →
   «Разрешить». В журнале появится `chat_id`, в Telegram придёт тестовое сообщение.
   Если что-то не так — запустите функцию `check`: она по пунктам покажет
   токен, таблицу, `chat_id` и ответ Telegram.
7. **Развернуть → Новое развёртывание → Веб-приложение**:
   «Запуск от имени: **Я**», «Доступ: **Все**» → «Развернуть» → скопируйте URL
   (заканчивается на `/exec`).
8. Вставьте этот URL в `js/main.js`:

```js
scriptUrl: 'https://script.google.com/macros/s/AKfy.../exec',
```

9. Проверьте: заполните анкету на сайте → в таблице появится строка,
   в Telegram — сообщение.

Важно: после каждой правки скрипта публикуйте новую версию —
**Развернуть → Управление развёртываниями → карандаш → «Версия: Новая»**.
Иначе сайт продолжит обращаться к старой версии.

Если что-то не приходит: запустите в Apps Script функцию `testAnswer` — она
добавит тестовую строку и отправит сообщение. Так видно, работает ли таблица
и Telegram по отдельности. Функция `check` печатает состояние по пунктам.

Если Google **не даёт выполнить** скрипт:

| Что видно | Причина и решение |
|---|---|
| «Приложение заблокировано» / «This app is blocked» | Аккаунт корпоративный или учебный, админ запрещает сторонние скрипты. Нужен личный `@gmail.com` — настройками это не обходится |
| Нет кнопки «Дополнительные настройки», только «Назад» | То же самое: доступ для аккаунта закрыт |
| «Script function not found: setup» | Файл не сохранён (Ctrl+S) или вставился не весь код |
| «Не удалось выполнить скрипт» без деталей | Внизу откройте «Журнал выполнения» — там настоящая ошибка |
| Ошибка про таблицу / `getActiveSpreadsheet` | Привязка больше не обязательна: скрипт создаст таблицу сам и напишет адрес в журнал |

Таблицу можно не создавать заранее вообще: если запустить скрипт из
[script.google.com](https://script.google.com) (автономный проект), он сам
создаст «Свадьба — ответы», сохранит её id и напечатает ссылку в журнале.

### Вариант 2: Formspree — ответы на почту

1. Откройте [formspree.io](https://formspree.io), зарегистрируйтесь (бесплатно до 50 отправок в месяц).
2. **New Form** → название «Свадьба — RSVP», укажите свою почту → создайте.
3. Скопируйте endpoint вида `https://formspree.io/f/mnqkzbcd`.
4. В `js/main.js` вставьте его в `CONFIG.formEndpoint`:

```js
formEndpoint: 'https://formspree.io/f/mnqkzbcd',
```

## Как выложить в интернет

### Быстро, без Git: Netlify Drop

1. Заархивируйте папку `wedding` в ZIP (или просто перетащите папку).
2. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащите папку в окно — через 5 секунд получите ссылку вида `https://random-name.netlify.app`.
4. «Claim site» → **Site settings → Change site name** → `ekaterina-artem` →
   ссылка `https://ekaterina-artem.netlify.app`.
5. Обновить сайт — снова перетащить папку.

### GitHub Pages (если хочется через git)

```bash
cd wedding
git init
git add .
git commit -m "wedding invitation"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/wedding.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
Через минуту сайт откроется на `https://ВАШ_НИК.github.io/wedding/`.

Репозиторий должен быть **публичным** — на бесплатном аккаунте приватные репозитории
Pages не раздают. Секретов в проекте нет: токены нигде не хранятся.

## После деплоя — три штриха

1. **Красивая ссылка в чате.** В `index.html` раскомментируйте блок `og:` и замените
   `YOUR-SITE.ru` на настоящий адрес. Тогда Telegram/WhatsApp покажут карточку с фото
   (`assets/og-image.jpg`) вместо голой ссылки.
2. **Короткая ссылка.** Прогоните адрес через `clck.ru` или `is.gd` — в чате удобнее.
3. **QR-код** на бумажное приглашение — `qr-code-generator.com` или Яндекс.QR.

## Что стоит знать

- Сайт статический: гости ничего не «ломают», сервер не нужен, хостинг бесплатный.
- Google Fonts (Marck Script, Cormorant Garamond, Inter) грузятся из интернета.
  Если нужен полностью автономный сайт — скачайте `.woff2` в `assets/fonts/` и
  перепишите `@font-face` в `css/style.css`.
- Фото на обложке — стоковое (Unsplash, бесплатная лицензия), замените на своё.
  Пока не заменили, оно работает как плейсхолдер.
